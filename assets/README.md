# Ассеты

- `models/` — модели; предпочтительно GLB/glTF, без зависимости от установленного Blender.
- `textures/` — текстуры, преимущественно небольшие; без преждевременного массового изменения импорта.
- `materials/` — общие материалы `.tres`.
- `audio/` — звуки; при наполнении разделяем на `ambience/`, `sfx/`, `voices/`.
- `fonts/` — шрифты с лицензиями и поддержкой нужных языков.
- `ui/` — графика интерфейса.

Имена файлов и папок — `snake_case`, латиница. Сохраняем лицензии сторонних ресурсов.
Настройки импорта `*.import` коммитим рядом с ассетами; кэш `.godot/` — нет.
Сложные исходники DCC держим вне импортируемых папок либо в папке с `.gdignore`.
Git LFS пока не настроен: перед добавлением тяжёлых ассетов согласуем его с командой.
