# Игровые данные

Здесь будут ресурсы смен, событий, камер и вопросов, отдельно от UI.
Начальный вариант: типизированные Godot Resources (`.tres`), классы в `scripts/data/`.

Договорённости для прототипа:
- Стабильные ID камер, фактов, вопросов и вариантов ответа.
- Правильный ответ задаётся ID, а не текстом или позицией кнопки.
- События имеют время начала и длительность окна наблюдения.
- Таймлайн продолжается при переключении камеры и выходе из компьютера.
- Все данные вымышлены. Формат из бэклога — предложение, не готовый парсер.

Не создаём фиктивные `.tres` до появления их классов и потребителей.
