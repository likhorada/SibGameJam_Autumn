# CCTV prototype — 2026-10-30

Локальный технический прототип просмотра **вымышленных** камер. Не готовая смена:
таймлайна с уликами, реального микрофонного звука, теста и угроз пока нет.

## Проверить в игре

1. F5 → сесть за ПК → двойной клик по **CCTV** (третья иконка).
2. Верхний выпадающий список — камеры магазина и двора, по две на локацию.
3. Удерживать `<` / `>` для поворота, `ZOOM -` / `ZOOM +` для приближения.
4. Мотор запускается с задержкой, разгоняется, немного докручивается после отпускания.
   На пределе появляется `LIMIT`. Управление только кнопками, без горячих клавиш.
5. Короткие замирания/помехи при работе мотора — намеренные. Цвет/ЧБ — свойство камеры.
6. `MIC +` / `MIC -` показывает наличие микрофона. **Звук ещё не подключён**:
   нет фиктивной шкалы громкости или обещания слышимого разговора.
7. При переключении, повторном открытии, восстановлении из панели задач и возвращении
   за ПК камера переподключается **с исходным поворотом и зумом**. Старый кадр скрыт
   во время подключения. Действия манекенов при этом не перезапускаются.
8. Блокнот можно держать рядом или поверх видео: поток продолжает работать, управление
   камерой освобождается. Esc сразу поднимает игрока, включая открытый список камер.

## Добавить камеру без кода

1. Открыть свою обычную сцену с корнем `Node3D`.
2. Перетащить `scenes/cctv/cctv_camera.tscn` из FileSystem в дерево сцены.
3. Передвинуть и повернуть **корень экземпляра**. Камера смотрит вдоль локальной **-Z**;
   отрицательный поворот X направляет её вниз. Корпус и головка уже входят в сцену.
   Для предпросмотра можно раскрыть экземпляр через Editable Children, выбрать
   `Head/Camera3D` и включить стандартный Preview в 3D-редакторе.
4. Выбрать корень камеры и заполнить свойства Inspector:

| Свойство | Значение |
| --- | --- |
| `Camera ID` | Обязательный уникальный ID среди всех подключённых локаций |
| `Display Name` | Название в списке, например `CAM-05 / СКЛАД` |
| `Location Label` | Группа/место. Список сначала сортируется по этой строке |
| `List Order` | Порядок внутри группы; при равенстве — по ID |
| `Monochrome` | Чёрно-белое изображение вместо цветного |
| `Has Microphone` | Только наличие микрофона, пока без реализации звука |
| `Pan Limit Degrees` | Симметричные пределы относительно исходного направления |
| `Pan Speed Degrees` | Скорость мотора |
| `Acceleration Degrees` | Разгон/торможение, влияет на остаточный ход |
| `Command Delay` | Пауза перед началом новой команды |
| `Base Fov` | Исходный угол обзора; применяется при запуске |
| `Max Zoom` / `Zoom Speed` | Максимальный оптический зум и скорость |
| `Interference Seconds` | Длительность замирания/помех при команде и движении; 0 отключает их |

5. Сохранить локацию. Для уже подключённой локации больше ничего не нужно: после
   запуска её камеры обнаруживаются автоматически. Пустые и повторяющиеся ID
   пропускаются с предупреждением, не подменяют друг друга молча.

## Подключить новую локацию без кода

1. Создать и сохранить `.tscn` с корнем `Node3D`, геометрией, освещением и CCTV-камерами.
2. В `scenes/main.tscn` выбрать узел **CCTVSystem**.
3. В Inspector добавить свою сцену в массив **Locations**. Сохранить главную сцену.
   Для изменения набора по умолчанию можно вместо этого открыть
   `scenes/cctv/cctv_system.tscn` и изменить тот же массив там.
4. F5 → ПК → CCTV. Приложение само найдёт камеры; скрипты и список приложений менять не надо.

Локации инстанцируются один раз при запуске. Камеры, добавленные в редакторе,
появятся при следующем запуске; динамическая регистрация во время игры не реализована.
Тестовые места специально маленькие: система разносит их на 100 единиц по X
в собственном 3D-мире, дальность CCTV-камеры — 65 единиц. Это не система стриминга
больших карт: не делайте локации шириной в сотни метров без изменения этой схемы.
Не добавляйте WorldEnvironment в каждую локацию: общий ambient/background задаёт система;
местные OmniLight3D/SpotLight3D работают как обычно. Сценарии локаций не должны
полагаться на координаты основной квартиры или абсолютные позиции соседней локации.

Варианты по умолчанию:

| ID | Место | Видео | Микрофон |
| --- | --- | --- | --- |
| `shop_wide` | Магазин, зал | Цвет | Нет |
| `shop_checkout` | Магазин, касса | Ч/Б | Есть |
| `yard_wide` | Двор, общий обзор | Ч/Б | Нет |
| `yard_entrance` | Двор, вход | Цвет | Есть |

В локациях — обычные редактируемые MeshInstance3D, вывески, цветные коробки и один
движущийся манекен. `test_patrol.gd` — повторяющееся тестовое движение, **не** игровой таймлайн.

## Производительность и устройство

- `scripts/cctv/cctv_system.gd`: один `SubViewport`, собственный World3D, список локаций
  и камер, переподключение. По умолчанию **480×270, до 18 обновлений в секунду**.
- `scripts/cctv/cctv_camera.gd`: настройки, панорамирование, задержка, инерция, FOV-зум.
- `scripts/ui/desktop/cctv_app.gd`: список, показ изображения, кнопки, статусы.
- `assets/shaders/cctv_feed.gdshader`: дешёвый canvas-эффект Ч/Б, зерна и помех.
- Только выбранная камера становится текущей. Нет набора постоянно живых render targets.
- Сворачивание, закрытие и вставание выключают обновления render target, но обычные
  скрипты и анимации локаций продолжаются. Полностью перекрытое другим окном CCTV
  пока не определяет перекрытие и продолжает рендериться.
- Нет реальных камер, сети, внешних сервисов, файловых операций в игре или звуковых потоков.
- Переключение фокуса на другое приложение/«Пуск», потеря фокуса игры и уход от ПК
  отменяют команду немедленно; обычное отпускание мыши оставляет короткое торможение.
- Основная сцена содержит один экземпляр CCTVSystem; отдельно запущенная сцена рабочего
  стола без системы корректно показывает «Нет подключённых камер».

## Проверки

```powershell
godot --headless --editor --path . --import
godot --headless --path . --script res://tests/cctv_smoke.gd
godot --path . --script res://tests/cctv_smoke.gd
godot --headless --path . --script res://tests/desktop_smoke.gd
godot --path . --script res://tests/prototype_smoke.gd
godot --path . --script res://tests/camera_motion_smoke.gd
```

Для снимков: добавить `-- --capture-dir=C:/existing/folder` к запуску CCTV-теста
с настоящим дисплеем. В тесте проверяются регистрация, свойства и четыре комбинации,
один viewport, фактические цвет/ЧБ пиксели, задержка/инерция/ограничения, GUI-удержание
и отпускание вне кнопки, переподключение, независимое движение, заметки, минимизация,
закрытие, Esc/возвращение и маленькая рабочая область. Отдельная проверка создаёт
новую обычную PackedScene с камерой и подключает через `Locations`, без скрипта локации.

Web на Windows, Node 22+ и обычный Chrome:

```powershell
godot --headless --path . --export-release "Web" build/web/index.html
node tools/cctv_web_check.mjs
```

Chrome можно переопределить переменной `CHROME`. Сервер привязан только к localhost,
браузер запускается с отдельным временным профилем и отключённым background throttling.
Снимки — `%LOCALAPPDATA%/Temp/opencode/cctv_web_*.png`; профиль там же, отдельно от
обычного профиля пользователя. Скрипт проверяет загрузку/ошибки консоли и выполняет
ввод, но визуальную корректность снимков нужно проверить отдельно. Он зависит от
стартовой расстановки квартиры и размеров окон; не универсальный UI-тест.

## Выполнено локально

- Godot 4.6.2 Compatibility: импорт и CCTV smoke в headless и обычном окне — PASS.
  В обычном окне дополнительно проверены пиксели цветного/ЧБ изображения.
- Регрессии: desktop smoke, квартира/10 циклов ПК и движение камеры — PASS.
- Чистая копия **только из Git index**, без незакоммиченных правок сцены, темы,
  блокнота и импортов моделей: импорт, headless CCTV/desktop и обычные тесты квартиры
  и камеры — PASS. Web и Windows release-экспорты из этой копии — PASS.
- Обычный Chrome по локальному HTTP, в том числе чистая сборка: выполнены реальные
  клики по списку всех четырёх камер, удержание поворота/зума с отпусканием вне кнопки,
  набор заметки, минимизация и восстановление, 640×360 и Esc → комната. Просмотрены
  снимки Ч/Б/цвета, разных мест, `PAN +11° / ZOOM 1.5x`, сброса `0° / 1.0x`, заметок
  и выхода. В успешных прогонах нет ошибок браузерной консоли.
- Windows EXE из чистой копии: headless-запуск на 10 кадров — PASS, stderr пуст.
  Интерактивный просмотр отдельного EXE не проверялся.

Firefox, слабое железо и длительное использование человеком не проверены. Потеря
фокуса в smoke проверяется вызовом обработчика уведомления, не настоящим Alt+Tab.
Ощущение вязкости/степень помех требует ручной приёмки; параметры доступны в Inspector.
