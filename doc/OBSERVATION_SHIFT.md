# Первый наблюдательный забег

## Как играть

1. F5 → «Играть» → сесть за ПК → завершить вводную переписку RELAY.
2. После последнего ответа начинается **60 секунд** на осмотр и взлом.
   В CCTV / ОФИС / DESK прочитай четыре цифры на мониторе. Запиши в Блокнот.
3. Открой **ALARM.sh** двойным кликом или через «Пуск», нажми кнопку запуска.
   До завершения инструктажа кнопка заблокирована. Звука сирены пока нет.
   Просрочка завершает забег с «Планом Б».
4. Цель в охристой куртке покидает офис (14 секунд после тревоги).
   Принудительный выход из ПК → **[ТЕСТ ПУГАЧКИ]**, пять секунд ходьбы без входа в ПК.
5. Магазин стартует сразу после паузы. Цель идёт к тыквам, задерживается,
   берёт один напиток, несёт его на кассу, ждёт и уходит. Весь маршрут — 62 секунды.
   Напитки: чай, кофе, красное вино, зелёная газировка. Выбор случайный на забег.
6. Ещё одна пятисекундная заглушка → улица. Через 12 секунд цель достигает
   слепой развилки и выбирает случайно переулок, аллею или парк.
   Проверяй камеры веток: там есть другие прохожие. Полный маршрут — 56 секунд.
7. После улицы HUD просит вернуться к ПК. При посадке с питанием автоматически
   открывается RELAY с вопросами: код (3 варианта), напиток (4), направление (3).
   Только **3/3** даёт победу. Угаданные ответы принимаются, просмотр не отслеживается.

До взлома случайные отключения заблокированы. После запуска разрешается обычная
система питания с её существующим cooldown. Таймлайн не останавливается при
отключении света, выходе из ПК, открытии Блокнота или dev-панели.
Пугачка ждёт завершения активного события ThreatManager и восстановления питания:
она больше не прерывает починку. Во время ожидания следующий маршрут не начинается.
На время самой пугачки новые опасные события и отключения питания заблокированы.
Если игрок переждал полицию в укрытии, следующая пугачка не вытаскивает его наружу.
Если улица закончилась без питания, отчёт ждёт восстановления и входа в ПК.
Отчёт также ждёт завершения уже начатой угрозы. После улицы новые случайные
угрозы и отключения больше не запускаются; ручные dev-команды остаются тестовыми.
Новый забег создаёт новые факты, чистую переписку и таймер.

## Где менять

- `data/observation/shift.gd`: точки маршрута, длительности, события take/checkout,
  напитки и три уличных выхода.
- `scripts/observation/shift_director.gd`: состояния INTRO → DEADLINE → ROUTE →
  WAITING_SCARE (если нужно) → SCARE → ROUTE … → REPORT → ENDED;
  выбор фактов, срок, отчёт, переходы.
- `scripts/cctv/observation_location.gd`: временный процедурный low-poly blockout
  офиса/магазина/улицы, цель и прохожие. Marker3D маршрута создаются директором.
- `CCTVSystem.replace_location()`: освобождает предыдущую локацию и обновляет
  каталог камер в **одном** существующем SubViewport.
- `ChatSession.questions`: вопросы текущего отчёта; `live_report` исключает
  выдачу старых тестовых ответов. Старый dev-опрос сохранён отдельно.
- `data/translations/ui.csv`: новые ключи `OBS_*`, RU/EN.

F7 → **DEV: завершить маршрут / тестовую пугачку** ускоряет проверку.
Отдельная старая команда тестового отчёта отключает сценарный прогресс этого забега.
`observation_shift_enabled=false` в main позволяет тестировать прежние CCTV-сцены
изолированно (используется только старым smoke-тестом камер).

## Будущие пугачки

Сейчас реализована только явно помеченная заглушка, **не десять пугачек**.
Точка запуска — `_finish_stage()`, завершения — `complete_scare()`.
При подключении настоящих событий пятисекундный автоотсчёт следует заменить их
сигналом завершения. До этого следующая локация не загружается и её NPC не движется.

## Проверки

`godot --path . --script res://tests/shift_smoke.gd` — сквозной native-прогон:
таймер, запуск, смена камер, покупка без питания, прерывание щитка, улица,
финальный отчёт с реальными фактами, победа и просрочка. Скриншоты:
`%LOCALAPPDATA%/Temp/opencode/shift_{office,shelf,checkout,street}.png`.

Web: в отдельной копии main scene = `tests/shift_fixture.tscn`, убрать `tests/*`
из исключений экспорта. Выполнить release Web export, затем:

```
$env:CHAT_WEB_ROOT = '<папка экспорта>'
$env:SHIFT_WEB = '1'
node tools/chat_web_check.mjs
```

Chrome/WebGL2: PASS — реальный клик запуска сигнализации, смена сцен,
ввод ответов с клавиатуры, RU/EN, 3/3 и 2/3. Таймлайн в browser fixture ускоряется
тестовыми командами, production их не содержит. Native shift smoke — PASS.
Регрессии chat/desktop/menu/power/CCTV — PASS. В headless при быстром выходе
встречаются прежние предупреждения о двух WAV playback амбиента (см. AMBIENCE.md).
Художественные модели, полноценные анимации, сирена и реальные пугачки ещё не готовы.
