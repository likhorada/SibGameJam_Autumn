# Главное меню — Mutual Observer

F5 запускает заставку `sample intro`, затем меню. F6 на `scenes/main.tscn`
по-прежнему запускает квартиру напрямую. Заставка длится 3 секунды; клик,
Enter, Space или Esc пропускают её. До загрузки сцены — чёрный экран без логотипа Godot.

## Художнику: заменить фон без кода

1. Открой `scenes/menu/backgrounds/shop.tscn` или `yard.tscn`.
2. Сохрани копию под новым именем. Корень — обычный **Node3D**.
3. Замени дочерний **Set** своей геометрией. Текущие Set — экземпляры игровых
   тестовых локаций; для независимых изменений заменяй экземпляр, а не исходную
   игровую локацию. Можно добавить AnimationPlayer с зацикленной анимацией.
4. Настрой свет и **WorldEnvironment** в этой сцене.
5. Выбери **Camera3D**, передвинь/поверни, включи Preview в 3D-редакторе.
   Камера должна иметь **Current = On**, оставаться неподвижной и смотреть на декорацию.
   Достаточно одной камеры; скрипты и специальные CCTV-узлы не нужны.
6. Открой `scenes/menu/menu.tscn`, выбери **Background**.
7. В Inspector → **Backgrounds** добавь свою `.tscn`. Удали ненужные элементы списка.
8. F6 на сцене меню: случайно выбирается один фон на весь сеанс меню.
   Для проверки конкретного ракурса временно оставь в списке только его.

Одновременно инстанцируется и анимируется только один фон, один SubViewport.
Ресурсы списка PackedScene являются зависимостями меню; это не потоковая загрузка
произвольно больших наборов ассетов. Делай сцены лёгкими.
По умолчанию фон рендерится в 640×360 с частотой 18 Гц; **Feed Size**, **Feed FPS**
и **Monochrome** доступны на Background. Поверх кадра применяется существующий
`cctv_feed.gdshader`. Таймкод вымышленный, отсчитывает время с открытия меню.
Пустой список даёт тёмный фон, кнопки продолжают работать.

## Настройки и перевод

- Громкость 5–100%, общая шина Master. Ноль вызывает короткую шутку.
  Музыка и звуковые эффекты пока не добавлены.
- Чувствительность 0.0005–0.006, исходная 0.0022. Применяется при создании игрока.
- Полноэкранный режим включается действием пользователя. В Web он зависит от
  разрешения fullscreen у страницы/iframe. После выхода через браузер состояние
  переключателя обновляется. Fullscreen намеренно не включается автоматически.
- RU/EN переключается сразу в меню, игровые интерфейсы используют выбранный язык.
  Первый язык берётся из системы/браузера: ru → русский, остальные → английский.
- Параметры хранятся в `user://settings.cfg`, в Web — в хранилище данного сайта.
  Запись откладывается на 0.3 секунды при движении ползунка, также выполняется
  при выходе из панели/запуске игры. Очистка данных сайта удалит настройки.
- **`data/translations/ui.csv`** — таблица UTF-8: ключ, английский, русский.
  Менять текст можно в табличном редакторе. Godot автоматически импортирует
  `ui.en.translation` и `ui.ru.translation`. Строки с запятыми заключай в кавычки.
  Экспортированные `.translation` также сохранены рядом с CSV: проект использует их
  напрямую и так чистый клон не показывает ошибку отсутствующего ресурса до импорта.
  `%d`, `%s`, `%02d` и прочие форматные вставки нужно сохранять.
- Название, `sample intro`, `to be filled`, пользовательские заметки и технические
  идентификаторы камер не переводятся. Подписи камер, подсказки, окна и сообщения — переводятся.

«Выход» скрыт в Web. «Играть» загружает квартиру, затем удаляет меню вместе с фоном.
Возврат в меню, сохранение прогресса и меню паузы не входят в эту реализацию.

## Проверки

```
godot --headless --editor --path . --import
godot --path . --script res://tests/menu_smoke.gd
godot --headless --path . --export-release Web build/web/index.html
node tools/menu_web_check.mjs
```

Smoke проверяет интро, один фон, ограничение громкости, переводы, панели,
переход в игру, применение чувствительности и освобождение фона.
Chrome harness управляет настоящим меню: настройки, fullscreen, RU/EN,
титры, 640×360, перезагрузка и запуск игры с захватом мыши.
Снимки `%LOCALAPPDATA%/Temp/opencode/menu_web_*.png` требуют визуальной проверки.

### Результаты локальной проверки

- Godot 4.6.2 Compatibility: импорт и native `menu_smoke.gd` — PASS.
- Native `prototype_smoke.gd`, `stamina_smoke.gd`; headless
  `desktop_smoke.gd`, `cctv_smoke.gd` — PASS.
- Обычный Web export, Chrome через локальный HTTP: fullscreen входит/выходит,
  настройки и титры открываются, переход в квартиру и pointer lock — PASS.
- Просмотрены снимки EN/RU, ограничения громкости, титров, 640×360 и повторного
  открытия страницы: русский язык и 5% сохранены, панели помещаются в экран.
- Повторный браузерный CCTV harness проходит через новое меню без ошибок консоли;
  проверен снимок английских подписей рабочего стола и камеры магазина.
- Проверки выполнены на текущем рабочем дереве, включая существующие локальные
  настройки сцены/темы. Firefox, iframe игрового хостинга и слабое железо не проверены.
  Слышимое изменение громкости проверить пока нечем: аудиоконтента нет.
