# Электричество, щиток и dev-меню

## Проверить быстро

1. F5 → «Играть». **Удерживай F7 полные 5 секунд**.
2. В dev-панели нажми **«Отключить питание»**, затем «Назад» / Esc.
3. Нажми ЛКМ для захвата мыши, открой дверь в общий коридор через **E**
   (теперь она изначально закрыта), пройди к щитку в конце коридора
   (координаты щитка примерно `4.2, 1.45, -6.82`). Светит только слабый фонарик.
4. Наведи прицел на корпус → **E**. Камера приближается, курсор свободен.
5. Наведи на ручку и удерживай ЛКМ **3.5 секунды**. Ручка движется вверх:
   **курсор нужно вести за ней**. Если увести курсор или отпустить ЛКМ — возврат
   вниз со скоростью полного хода за **1.2 секунды**.
6. Полностью поднятый рубильник фиксируется ON. Порядок произвольный, один за раз.
7. **Esc или WASD** позволяют отойти. Зафиксированные остаются, недотянутые падают.
8. После четырёх ON свет включается, фонарик гаснет, камера возвращается к игроку.
   При необходимости нажми ЛКМ для захвата мыши. ПК снова работает.

Для короткого ручного теста без пробежки можно открыть `tests/power_fixture.tscn`
через F6: это настоящая квартира со стартом у щитка, автоматические отключения
в этой **тестовой сцене** выключены. В обычный экспорт `tests/*` не входит.

## Рандом и питание

- Первые **120 секунд** новой игры и после каждого ремонта защищены.
- Затем каждый полный подходящий интервал в одну секунду — независимый бросок
  с вероятностью **2%**. Момент не выбирается заранее, верхнего предела ожидания нет.
  Среднее ожидание после защиты — 50 секунд, но это не гарантия.
- Пока питание выключено, новые отключения не происходят; новые четыре OFF
  выставляются только при переходе ON → OFF. Самовосстановления нет.
- При отключении выключаются Light3D квартиры, затемняется ambient и экран ПК,
  автоматически включается фонарик со следованием за текущей камерой:
  основной мягкий конус и слабый широкий ближний засвет. Ближний конус слегка
  направлен вниз, освещает пол и предметы рядом, но затухает на 2.2 м.
  Оба источника с тенями, чтобы свет не проходил через стены; объёмного тумана нет.
- Если игрок за ПК / садится / встаёт, переход прерывается, игрок переносится
  на существующую безопасную ExitPoint. Приложения и заметки сохраняются.
  ПК недоступен до ремонта. CCTV viewport отключён, но жизнь локаций не останавливается.
- В крупном плане ходьба отключена. Потеря фокуса, отпускание ЛКМ, уход курсора,
  выход и dev-панель прерывают удержание. Уход курсора не переносит удержание
  на соседний рубильник: для нового захвата нужно отпустить и снова нажать ЛКМ.
- На Esc в Web не запрашивается pointer lock: браузер может запретить его в этом
  же событии. После выхода достаточно ЛКМ с учётом существующей паузы браузера.

| `Random Outages Enabled` | On; Off удобно для ручных тестов |

**`scenes/power/fusebox.tscn` → Breakers** (`scripts/power/fusebox.gd`):
`Raise Seconds = 3.5`, `Fall Seconds = 1.2`, `Raise Sound`, `Fall Sound`, `Latch Sound`.
Сцена встроена дочерним узлом в существующий `Apartment/Fusebox`.
**CloseView** — обычный Marker3D для крупного плана, редактируется без кода.
**Handles** содержит четыре экземпляра `lever.tscn`: геометрия заменяется в этой сцене.
`PickBody` должен оставаться на collision layer 2, это отдельная маска для курсора.
Номера ручек назначаются автоматически по порядку в Handles; нужно ровно четыре.

## Звук

Звуковых файлов в проекте нет — все слоты честно пустые, ничего не проигрывается.
Перетащи свои `.ogg` / `.wav` в соответствующие AudioStream-поля Inspector.
Подъём воспроизводится/повторяется, пока ручка поднимается; отмена останавливает
его и запускает возврат; фиксация — отдельный щелчок. Шина механики — SFX.
Не используй loop-файлы для одноразовых щелчков, возврата и включения.

Случайные шорохи работают только во время мини-игры: после случайной паузы
бросается шанс, выбирается непустой клип, источник ставится позади камеры.
Одновременно играет не более одного клипа, шина Ambience, громкость -16 dB.
При выходе, dev-панели и потере фокуса шорох прекращается. Это не враг и не ИИ.
Настрой расстояние и громкость дочерних MotionAudio / ClickAudio для механики.

## Dev-панель

Только внутри квартиры, не в меню. F7 удерживается **5 секунд подряд**;
раннее отпускание или потеря фокуса сбрасывают отсчёт. Во время перехода камеры
открытие ждёт стабильного режима. Мир и таймеры **не на паузе**.

- **Бесконечная выносливость**: заполнить запас, снять истощение и усталость,
  отключить расход. При выключении обычный расход возобновляется с полного запаса.
- **Отключить питание**: принудительное отключение, игнорируя кулдаун.
- **Восстановить питание**: тестовый обход четырёх рубильников.
- **Обнулить защиту**: следующий секундный бросок снова разрешён; это не гарантирует отключение.
- Статус: питание, секунды защиты, четыре флага фиксации.

**`Main/DevMenu → Enabled = Off`** полностью отключает панель перед публикацией.
По умолчанию она работает и в release/Web. Это намеренно доступный инструмент
для команды, не античит. Настройки dev не сохраняются между игровыми сессиями.

## Проверки

```
godot --headless --editor --path . --import
godot --headless --path . --script res://tests/power_smoke.gd
godot --path . --script res://tests/power_smoke.gd
```

Smoke проверяет защиту и секундный бросок, выключение света/ambient, запрет ПК,
скорости ручек, сохранение ON, ремонт, отключение в трёх состояниях ПК, заметки,
луч взаимодействия, крупный план, выход, F7 и unlimited stamina.

Для браузерного теста — временная копия проекта: main scene заменить на
`res://tests/power_fixture.tscn`, в Web preset временно убрать `tests/*` из исключений,
экспортировать в `build/power-web/index.html`. Затем `node tools/power_web_check.mjs`.
`POWER_WEB_ROOT` позволяет указать другой каталог. В production JS-моста нет.
Harness использует реальный F7, мышь и движущиеся 3D-ручки; тестовый JS-мост
даёт только телеметрию и команду входа в ПК для отдельной проверки отключения.

Скриншоты: `%LOCALAPPDATA%/Temp/opencode/power_web_*.png`.

  сохранение фиксации, ремонт, гашение фонарика и отключение за ПК — PASS.

  секундных проверок, а не длительным статистическим прогоном.

- Правка фонарика: мягкий основной конус и широкий ближний засвет. Native

  светлеют, поверхность за пределами дальности не меняется; power smoke — PASS.
  Dedicated Chrome fixture повторно экспортирован и прошёл весь power harness.
