# Звуки квартиры

`scripts/audio/ambient_director.gd` создаётся игровым `main.gd`, не в меню.
Все новые звуки используют существующую шину **SFX**.

- `ambient_noise.wav`: постоянный луп, -12 dB при включённом питании.
- `ambient_noise2.wav`: луп около ПК, -6 dB в радиусе 3 м от монитора;
  затухает к 7 м и останавливается. При возвращении включается снова.
- При отключении питания оба гула затухают за 0,35 с и останавливаются.
  Восстановление питания возвращает их с плавным входом.
- Раз в 10–20 секунд активной ходьбы: вероятность 7,5% проиграть один из
  `scratchin1–2.wav` / `knock1–3.wav`, -10 dB. Только с питанием, вне ПК,
  щитка и dev-панели. Уже запущенный разовый звук доигрывается;
  одновременно несколько случайных звуков не запускаются.
- `elecric_fixing.wav`: луп при удержании незащёлкнутого рычага щитка.
  Отпускание, уход курсора с рычага, защёлкивание, выход из мини-игры
  и потеря фокуса останавливают звук через существующий `cancel_hold()`.
- Итог забега останавливает амбиент.

Параметры директора редактируются в начале `ambient_director.gd`.
Три лупа включены через импорт WAV (`edit/loop_mode=2`, Forward).
Исходные WAV не изменялись; бесшовность стыка и громкость нужно оценить на слух.

## Проверка

```
godot --headless --path . --script res://tests/ambience_smoke.gd
godot --path . --script res://tests/ambience_smoke.gd
```

Godot 4.6.2 Compatibility: оба прогона PASS. Проверены режимы лупа, громкость
плееров, дистанция, отключение/возврат питания, запреты случайных звуков,
удержание/отпускание рычага и остановка на итоге. Native desktop smoke — PASS.
Power/chat/menu smoke headless — PASS; при быстром завершении desktop/menu
headless встречаются предупреждения о WAV playback, воспроизводимые также
в минимальном тесте с одним зацикленным плеером. Native desktop завершается чисто.
Release Web export выполнен без ошибок. Воспроизведение новых звуков в браузере
и субъективное качество звука не проверены.

Ручная проверка: F5 → играть → подойти к ПК/отойти → F7 выключить питание →
щиток, удерживать/отпускать рычаг → починить. Случайные события редкие:
временно увеличить `random_chance` для прослушивания, затем вернуть 0.075.
