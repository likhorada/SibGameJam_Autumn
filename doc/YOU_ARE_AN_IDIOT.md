# You Are An Idiot — атмосферный ивент ПК

**Только имитация внутри игры:** обычные Godot `Control`, рисованная карточка и
`AudioStreamPlayer3D`. Никаких настоящих окон ОС/браузера, сетевых запросов,
загрузки оригинального вируса, доступа к файлам или системных команд.
`about:blank` — нарисованный текст, не адрес для перехода.

## Поведение

- ID: `you_are_an_idiot`. В общем пуле, разрешены оба типа запуска, **только за ПК**.
- Появляется одно окно 320×220 в стиле браузера нулевых: английская надпись,
  три рисованных смайла, чёрно-белая статичная карточка. Мигания нет.
- Первое окно неподвижно и перетаскивается за заголовок. Рабочая кнопка — только ×.
- Первая попытка закрыть запускает движение всех окон. Каждая такая попытка добавляет
  **одну** копию; окна отскакивают от границ рабочей области, перетаскивание отключено.
- При первом достижении **8 окон** режим навсегда меняется на закрытие: последующие
  крестики действительно убирают окна, без возобновления размножения.
- Полный срок — **15 секунд от первого появления**, независимо от внимания игрока.
  Если закрыты все окна раньше, событие заканчивается после 0,2 с затухания звука.
- Звук — `assets/audio/creep_laugh.wav`: один пространственный источник у монитора,
  SFX, повтор до завершения. Количество окон не увеличивает громкость/число источников.
  Нормальное истечение тоже имеет короткое затухание; отмена очищает сразу.
- Можно перекрывать важные наблюдения CCTV — согласованное исключение для этого
  ивента. Сам маршрут не ставится на паузу, кроме обычного межсценового ожидания.
- Панель задач и меню выхода остаются над/вне области окон. Esc штатно выводит из ПК.
  Клики по пугачке не активируют приложения под ней; клавиатура не перехватывается.
- При выходе окна скрыты вместе с рабочим столом, но время и смех из компьютера
  продолжаются. При возврате до истечения срока видны оставшиеся окна.
- Изменение размера ограничивает окна новой рабочей областью. Опрос, отключение
  атмосферы, watchdog, конец забега и выгрузка убирают все окна и источник звука.

Пока в production-пуле только этот ивент: резерв межсценового события защищён от
случайной выборки. Поэтому при обычном наблюдении за ПК он прежде всего выпадает
на переходах, с разрешённым fallback-повтором при нехватке контента. Если на переходе
игрок ходит, ПК-ивент не запускается; неиспользованный освобождённый ID может позже
выпасть случайно. С добавлением остальных событий разнообразие даст общий директор.

## Где менять

- `scripts/atmosphere/you_are_an_idiot.gd` — время, копии, звук, завершение и очистка.
- `scripts/atmosphere/idiot_popup.gd` — отрисовка псевдобраузера, drag и bounce.
- `scenes/atmosphere/you_are_an_idiot.tscn` — сцена обработчика.
- `data/atmosphere/you_are_an_idiot.tres` — контексты и watchdog (17 с).
- `data/atmosphere/default.tres` — регистрация в общем пуле.

При изменении длительности события согласовать watchdog профиля: он должен оставлять
небольшой запас после нормального срока.

## Проверить вручную

F5 → Играть → сесть за ПК → удерживать F7 → **TriggerYouAreAnIdiot**.
Кнопка закрывает dev-меню и вызывает безопасный forced API директора. Из ходьбы,
при угрозе, отключённой атмосфере, опросе или другом ивенте запуск будет отклонён;
причина записывается в dev-статус. Обычный dev-селектор также содержит этот ID.

Попробовать: игнорировать окно, перетащить, нажать × семь раз, закрыть все восемь,
выйти через Esc, вернуться и изменить размер окна игры.

## Автотесты

```
godot --headless --path . --script res://tests/idiot_smoke.gd
godot --path . --script res://tests/idiot_smoke.gd
```

Web во временной копии: main scene `tests/idiot_input_fixture.tscn`, включить `tests/*`
в экспорт. После release Web export:

```powershell
$env:IDIOT_WEB_ROOT = '<каталог Web экспорта>'
$env:IDIOT_WEB = '1'
node tools/chat_web_check.mjs
```

Для общих lifecycle-проверок main = `tests/idiot_fixture.tscn` и обычный
`THREAT_WEB_ROOT` / `THREAT_WEB=1` runner. Все JS-команды и ускорение времени — только
в тестовых сценах, исключённых из production.

### Проверено (Godot 4.6.2 Compatibility)

- `idiot_smoke`: headless, настоящее desktop-окно и Chrome/WebGL2 release — PASS.
  Клики GUI, drag, рост/закрытие, повтор смеха, предел 8, ресайз, выход/возврат,
  оба типа запуска, fallback перехода, естественное/досрочное завершение,
  опрос, disable, watchdog, рестарт и выгрузка.
- Chrome input fixture: RU/EN, реальные F7/dev-кнопка, drag и крестики,
  панель задач/Esc, возврат, ресайз и очистка — PASS.
- Headless-регрессии: atmosphere, shift, threat, police, neighbor, outage,
  fairness, lifecycle, chat, desktop, power — PASS. В части прежних тестов
  остаются известные предупреждения об аудиоресурсах при завершении процесса.
- Скриншоты нативного теста: `%LOCALAPPDATA%/Temp/opencode/idiot_single.png`
  и `idiot_eight.png`; browser runner сохраняет `chat_web_idiot_*_{ru,en}.png`.
- Firefox, слабое железо и субъективный баланс громкости/скорости требуют приёмки.
