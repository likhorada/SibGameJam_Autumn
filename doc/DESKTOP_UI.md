# Игровой ПК — 2026-10-30

Собственная холодная серо-стальная оболочка: компоновка в духе XP, сдержанные рамки
и цвета 95/98. Это игровые `Control`, не настоящие приложения Windows.
Оболочка опубликована; новое CCTV-приложение готовится к локальной приёмке,
без push до отдельного одобрения. Подробности: `doc/CCTV.md`.

## Управление и состояние

- На рабочем столе **Блокнот**, **Калькулятор** и **CCTV**. Один клик выделяет,
  двойной запускает; Enter также запускает выделенную иконку.
- По одному экземпляру каждого приложения. Повторный запуск восстанавливает/поднимает окно.
- Заголовок перетаскивается. Все края и углы меняют размер; нижний правый угол отмечен.
- Кнопки заголовка: свернуть, развернуть/восстановить, закрыть.
  Двойной клик по заголовку тоже разворачивает/восстанавливает окно.
- Активное окно поверх остальных, заголовок выделен. Панель задач переключает окна;
  клик по кнопке уже активного окна сворачивает его.
- Заголовки не уводятся за пределы рабочей области, панель задач не перекрывается
  развёрнутыми окнами. При изменении размеров рабочей области окна ограничиваются заново.
- «Пуск»: два приложения и «Встать». Клик снаружи закрывает меню.
- **Esc всегда сразу поднимает игрока**, а не закрывает окно или «Пуск».
  Этот маршрут также подключён к контекстному меню TextEdit.
- При вставании меню закрывается, незавершённый drag/resize отменяется, текстовый фокус
  освобождается. При возвращении открытые окна, геометрия, заметка, undo и калькулятор сохранены.
- Вся информация — только в памяти текущей сцены. Перезапуск игры создаёт пустую заметку
  и калькулятор с нулём. Нет файлов, фоновых сервисов, доступа к реальным приложениям или save-файлов.
- Часы начинаются с условных **09:00**, идут по монотонному времени сеанса, в том числе
  вне компьютера. Это временная точка подключения будущего игрового таймлайна,
  не системные часы пользователя.

На Web Esc может запрещать pointer lock в том же событии клавиатуры. Поэтому выход по Esc
возвращает в комнату со свободным курсором: для обзора нужен ЛКМ после защитной паузы.
Выход кнопкой «Встать» пытается захватить мышь сразу, если браузер уже разрешает это.

## Блокнот

Обычный многострочный `TextEdit`: перенос строк, прокрутка, выделение, кириллица,
Ctrl+A/C/X/V/Z и стандартное контекстное меню. Внизу — счётчик символов.
Закрытие окна не удаляет текст. Нет форматирования, поиска, файловых диалогов
и запроса «Сохранить?»: заметка автоматически остаётся в памяти попытки.

Буфер обмена — стандартный механизм Godot/платформы, не собственный файловый ввод.
На Web его доступность зависит от браузера, разрешений и пользовательского жеста.
Нативный clipboard иногда может быть временно занят другим процессом Windows.

## Калькулятор

Цифры, десятичная точка/запятая, + − × ÷, =, ±, BS (Backspace), C и CE.
Кнопки и клавиатура работают только у активного приложения; клавиатура включает numpad.
Enter / = — результат, Delete — CE, C — очистить всё, F9 — сменить знак.

Обычная последовательная арифметика: `2 + 3 × 4 = 20`, без приоритета операций.
Повторное = повторяет последнюю операцию; повторный оператор заменяет ожидающий.
CE очищает текущий операнд, сохраняя ожидающую операцию; C сбрасывает всё.
Деление на ноль и переполнение дают понятную ошибку, цифра или очистка позволяют продолжить.
Ввод ограничен 14 цифрами, результат — до 10 десятичных знаков; абсолютное значение
результата от `10^14` считается переполнением. Это не научный калькулятор.

## Файлы и расширение

| Путь | Назначение |
| --- | --- |
| `scenes/ui/terminal_ui.tscn` | Корень рабочего стола, фон и рабочая область |
| `scripts/ui/desktop/terminal_desktop.gd` | Иконки, панель задач, меню, фокус, порядок окон и часы |
| `scenes/ui/desktop/desktop_window.tscn` + `desktop_window.gd` | Общая рамка, drag/resize, минимизация и maximize/restore |
| `scenes/ui/desktop/notepad.tscn` + `notepad_app.gd` | Текстовый редактор и статус |
| `scenes/ui/desktop/calculator.tscn` + `calculator_app.gd` | Кнопки, дисплей и клавиатурный ввод |
| `scripts/ui/desktop/calculator_model.gd` | Арифметика без UI, парсинга кода или eval |
| `assets/ui/desktop_theme.tres` | Цвета, рамки и общая тема |
| `assets/ui/*.svg` | Собственные векторные иконки, включая оконные кнопки; не требуют системных символов |

Окна и оболочка собирают повторяющиеся элементы программно. Контент приложений — отдельные
сцены. CCTV уже использует общий `DesktopAppWindow`; следующие приложения тоже
регистрировать в `TerminalDesktop`, а не рисовать второй независимый desktop.
Не добавлять глобальные менеджеры или реальные службы ОС ради окон.

## Проверки

```powershell
godot --headless --editor --path . --import
godot --headless --path . --script res://tests/desktop_smoke.gd
godot --path . --script res://tests/desktop_smoke.gd
godot --path . --script res://tests/prototype_smoke.gd
godot --path . --script res://tests/camera_motion_smoke.gd
```

`desktop_smoke.gd` проверяет арифметические сценарии/ошибки, одиночный/двойной клик,
реальные синтетические GUI-события перемещения и изменения размера, границы и минимумы,
maximize/restore, переключение окон и панели задач, ввод текста, undo, фокус,
сохранность заметок и стыковку с игровой сценой: W/E печатают, Esc поднимает даже из меню,
скрытый desktop не получает текст. Маршрут Esc из TextEdit popup проверяется через сигнал
его отдельного viewport. Native-версия дополнительно проверяет Ctrl+C/V;
headless-версия не проверяет системный clipboard.

Для снимка настоящего рендера:

```powershell
godot --path . --script res://tests/desktop_smoke.gd -- --capture-dir=C:/existing/folder
```

## Что принять руками

1. F5 → сесть за ПК → открыть оба приложения двойным кликом.
2. Перекрыть окна, переключить фокус, перетащить и изменить размер с разных краёв.
3. Свернуть/вернуть, развернуть/восстановить, закрыть и открыть заново.
4. Написать заметку, проверить кириллицу, выделение, копирование/вставку, undo и прокрутку.
5. Посчитать мышью и клавиатурой, попробовать дроби, C/CE и деление на ноль.
6. Нажать Esc при вводе и в «Пуске»: сразу встать. Сесть обратно: окна и текст на месте.
7. Уменьшить окно игры и проверить доступность приложений и панели задач.
