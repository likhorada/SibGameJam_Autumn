# PoliceRaid — этап 3

> Ниже исторический MVP. Актуальные правила и тесты: [THREAT_FAIRNESS.md](THREAT_FAIRNESS.md).

## Ручная приёмка

1. F5 → «Играть» → сесть за ПК. Удерживать **F7 пять секунд** → **TriggerPolice**.
   Панель закроется, прозвучат громкий стук и `heavy_knock.wav` вместо голоса.
   С первого стука идут **12 секунд**, видимого HUD-таймера нет.
2. Выйти из ПК обычным Esc / кнопкой. В Web Esc освобождает мышь: повторный ЛКМ
   после существующего browser cooldown возвращает захват, как и раньше.
3. Навести прицел на шкаф в комнате (около `-1.85, 1.05, 2.55`) или на матрас /
   раму кровати в спальне (`-1.7, 0.6, 5.1`) → **E**.
4. Внутри нельзя ходить; мышью можно немного смотреть по сторонам. У шкафа —
   настоящая узкая щель между дверцами, под кроватью — низкий ракурс с ножками.
5. После предупреждения полиция открывает комнатную дверь, даже если она закрыта.
   **6 секунд осмотра + 3 секунды ухода** нужно оставаться в укрытии.
   Если не спрятался, находишься в коридоре или вышел раньше — проигрыш.
6. После ухода затихают шаги, фигура исчезает. **E** безопасно возвращает ходьбу.
   Дверь остаётся **открытой**: перед следующим визитом соседа лучше закрыть её.
7. Можно вернуться к ПК: заметки, чат и таймлайн не сбрасываются. Таймлайн продолжает
   идти во время пряток, кроме существующего ожидания между сценарными этапами.

**Esc внутри укрытия только освобождает мышь, не выставляет игрока наружу.**
ЛКМ возвращает захват; затем E позволяет выйти. F7, потеря фокуса, DisableThreats
и отложенная сценарная пугачка тоже не вытаскивают игрока насильно.

## Реализация и ограничения MVP

- `PoliceRaid` — обычный зарегистрированный ThreatEvent, без отдельного генератора
  рандома. Полиция и сосед выбираются по общему расписанию и весам ThreatManager.
  Вторая угроза, случайное отключение или пугачка не накладываются на проверку.
- Простейшая low-poly фигура проходит по Marker3D `Apartment/PoliceRoute`, затем
  идёт обратно и удаляется в коридоре. Навигации, преследования и сложного поиска нет.
- Проверяется `Main.is_hidden()`, а не видимость капсулы / физический AI. Поэтому
  ни закрытая дверь, ни общий коридор не обходят требование спрятаться.
- Выход из укрытия во время осмотра/ухода проверяется сразу сигналом, а не только
  на следующем кадре. Смерть использует существующий итоговый экран с причиной
  `POLICE_DEATH`, без результата опроса. Реальный restart очищает укрытие и угрозы.
- Укрытие не меняет обычный контроллер движения и не уменьшает капсулу: ходьба
  выключена, текущая TransitionCamera получает заранее заданный ракурс и небольшой
  ограниченный поворот. Стоящая капсула остаётся в исходной безопасной позиции.
- Выходные Marker3D проверяются полной капсулой. Если первый выход загорожен,
  используется второй, затем исходная позиция. Если заняты все — игрок остаётся
  спрятанным с подсказкой, а не телепортируется в стену. Текущие статические точки
  проверены; тест дополнительно загораживает основной выход и использует запасной.
- Изменены только нужные greybox-пропы: шкаф получил полую визуальную оболочку
  вместо сплошного ящика; у кровати приподнята рама и добавлены ножки. Обычные
  проходы и стоячие коллизии сохраняются. Новых viewport, освещения или AI нет.

## Настройки и команды

- `data/threats/default.tres`: вес/включение, **Warning Seconds = 12**,
  **Max Active Seconds = 20**. Это watchdog: при зависшем обработчике он безопасно
  завершает проверку. При увеличении осмотра/ухода нужно учитывать этот предел.
- `data/threats/police_raid.tres`: **Search Seconds = 6**, **Departure Seconds = 3**,
  **Knock Interval = 4**, **Voice Delay = 0.9**, AudioStream-слоты и громкость.
- `scripts/threats/police_raid.gd`: фазы, звук, маршрут и проверка укрытия.
- `scenes/threats/police_officer.tscn`: временная фигура.
- `scenes/apartment/hiding_spots.tscn`, `scripts/apartment/hiding_spot.gd`: ракурсы,
  FOV, пределы поворота, выходы. Шкаф: ±12° по горизонтали, кровать: ±18°;
  оба: ±6° по вертикали. Поворот не перемещает камеру сквозь мебель.
- `scripts/main.gd`: режим HIDING, существующий луч/E, фокус и переключение камер.

В F7: **TriggerPolice**, **PoliceRaid** (включить/выключить только эту угрозу),
**DisableThreats**. Принудительный запуск обходит расписание, но не занятый слот,
пугачку, отсутствие питания или отключённую угрозу. Отключение активной проверки
убирает звук/фигуру, но не раскрывает укрытие и не закрывает открытую полицией дверь.
Рандом питания пока остаётся прежним до этапа CorridorEntity, см. THREATS.md.

## Звуки

Стук и звуки предупреждения/ухода — `heavy_knock.wav`, шаги — `steps.wav`;
открытие и закрытие комнатной двери — `door_click.wav`. Голосовые AudioStream-слоты можно
переопределить в ресурсе без переделки механики. Шина **SFX**, пространственные
источники. Случайный амбиент не перекрывает активную угрозу.

## Проверки

```
godot --headless --editor --path . --import
godot --headless --path . --script res://tests/police_smoke.gd
godot --path . --script res://tests/police_smoke.gd
```

`tests/police_checks.gd`: оба укрытия, луч/E, ограничение обзора и ходьбы,
выходы/запасной выход, потеря фокуса, PC-переход и заметки, полный срок предупреждения,
осмотр/уход, проигрыш вне укрытия/при раннем выходе, реальный restart, отмена,
рандом/TriggerPolice, отложенная пугачка и следующий сосед при открытой/закрытой двери.
В headless нет захвата мыши: реальный E и мышь проверяются native / браузером.

Release Web во временной копии: включить `tests/*` в preset и выбрать main scene:

1. `tests/police_fixture.tscn` — тот же общий smoke и реальный restart.

```powershell
$env:THREAT_WEB_ROOT = '<каталог Web-экспорта>'
$env:THREAT_WEB = '1'
node tools/chat_web_check.mjs
```

2. `tests/police_input_fixture.tscn` — реальный Chrome input:

```powershell
$env:POLICE_WEB_ROOT = '<каталог Web-экспорта>'
$env:THREAT_WEB = '0'
$env:POLICE_WEB = '1'
node tools/chat_web_check.mjs
```

Прогон RU/EN использует F7 → TriggerPolice, Esc из ПК, захват/повторный захват мыши,
E входа/выхода из шкафа и под кровать, реальное движение мыши и удержание W,
безопасный выход после ухода и ранний выход со смертью. JS-мост только ставит игрока
к мебели и вручную шагает часы угрозы; он не измеряет человеческое время реакции
и исключён из production вместе с `tests/*`. При смене режима убрать старые env-пути.

Godot 4.6.2 Compatibility: police smoke headless/native, общие проверки и input
в release Chrome WebGL2 RU/EN — PASS. Native/Web скриншоты укрытий и смерти просмотрены.
Регрессии: native prototype/neighbor, headless threat/neighbor/shift/power/chat/
desktop/ambience/menu/CCTV — PASS. Chrome Web input соседа и сквозной shift harness
(RU/EN, 3/3 и 2/3) — PASS.
В headless иногда остаются прежние предупреждения WAV playback при завершении;
native police smoke завершается без них. Firefox, слабое железо, субъективная
слышимость клипов и баланс времени спасения с живым плейтестером пока не проверены.
